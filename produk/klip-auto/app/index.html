Pasang Jembatan Link YouTube Lokal (15 Detik)

Agar pemrosesan link YouTube berjalan murni lewat koneksi internet rumah/kantormu tanpa bergantung ke layanan luar, aktifkan ekstensi pendamping ringan kami di Chrome atau Edge:

1. Unduh Paket Ekstensi Jembatan Lokal (.ZIP) lalu ekstrak ke satu folder di laptopmu (atau unduh satuan: manifest.json, background.js, content-bridge.js).
2. Buka chrome://extensions atau edge://extensions.
3. Nyalakan sakelar Mode pengembang (Developer mode) di kanan atas.
4. Klik Muat yang belum dikemas (Load unpacked) lalu pilih folder hasil ekstrak tadi, kemudian muat ulang tab ini.
