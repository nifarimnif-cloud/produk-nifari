# Produk Digital — Nifari

Workspace utama untuk challenge **10 Produk Digital (Landing Page + Web App)**.

## Struktur Folder
- `AGENTS.md` — Standar dan aturan kerja pembangunan produk (LP & Web App).
- `halaman-tes/` — Halaman tes awal untuk memastikan alur GitHub + Cloudflare Pages berjalan normal.
- `produk/<nama-produk>/` — Setiap produk memiliki folder sendiri berisi:
  - `lp/` — Landing Page (1 file HTML utuh < 1 MB)
  - `app/` — Web App lengkap untuk pembeli
  - `SETOR.md` — Ringkasan setoran, link live, screenshot, dan hasil tes
